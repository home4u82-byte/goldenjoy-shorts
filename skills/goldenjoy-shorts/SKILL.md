# goldenjoy-shorts — 영화 숏폼 제작 스킬

**★코어 먼저**: 제작 시작 전에 같은 플러그인의 `shorts-core` 스킬(SKILL.md)을 **먼저 읽는다**. 프리셋 무관 공통 규칙(품질 3기준·대본 골격·컷 문법·화자 중앙·덕킹·게이트 G0~G17·장부)의 단일 원본은 코어다 — 겹치면 코어가 기준이고, 이 문서는 이 프리셋 고유 사항(나레이션 문법·TTS·자막·헤드라인 공식·업로드 양식·파이프라인 순서)과 실측 함정 세부를 담는다.

**빌드 스크립트**: `templates/`의 build·merge·finish·make_sfx 템플릿을 프로젝트 폴더에 복사한 뒤 **상수(소재 경로·컷 테이블·텍스트)만 바꿔 쓴다.** 로직을 새로 짜지 마라 — 수십 회의 반려를 거쳐 확정된 것이다. 검증 도구는 `shorts-core/tools/`에서 복사한다.
**설정**: 플러그인 루트 `config.json` (`config.example.json` 복사) — 작업 폴더(work_root)·API 키 경로. 시작 전 `python3 setup/check_setup.py`로 환경을 점검한다.

## 절대 규칙 (하나라도 어기면 반려된다 — 전부 실제 반려에서 나온 것들)

1. **검정 프레임 0** — 첫 프레임부터 그림이 있어야 한다. 최종 합성에서 `[0:v]setpts=PTS-STARTPTS` 필수. 렌더 후 frame0 밝기 실측(평균 밝기 > 10).
2. **대사 립싱크 1:1** — 대사(D블록) 비디오는 오디오와 같은 원본 시각. 무음 제거로 조각난 대사는 조각마다 싱크 컷. 대화 시퀀스는 원본 영화의 샷 리듬(교차 편집)을 프레임 단위로 복제한다.
3. **주 피사체 중앙 = 기계 측정 — 사람이든 사물이든 전부**. 눈대중 금지. 얼굴은 눈눈코 삼각형 무게중심(`tri_measure.py`), 얼굴 없는 컷(사물·차량·문서)은 배경 제외 무게중심(`center_measure.py`) → `x = clamp(중심-400, 0, W-800)` → 렌더 후 `center_verify.py` ±90px 검증. 와이드·액션 컷은 예외(구도 유지).
   **★대화 장면은 예외 없음 — 프레임 가운데는 항상 말하는 사람**. 투샷·OTS라도 그 순간 **발화 중인 화자의 얼굴**을 중앙에. 한 컷 안에서 화자가 바뀌면 화자 전환 시각에서 컷을 분할하고 x를 각각 다시 잰다.
4. **컷은 장면 경계를 넘지 않는다** — `scene>0.18`로 경계 추출, 모든 컷은 단일 장면 안. 컷 끝은 경계에서 **0.15~0.2s 당긴다**(검출 경계가 실제보다 늦어 다음 장면이 샌다).
5. **크롭은 800×800, y는 활성화면 상단**(`cropdetect`로 영화마다 재실측). 1920×1080 파일에 시네스코가 레터박스로 들어 있으면 실측 y, 파일 자체가 1920×800이면 y=0. x만 인물 따라 이동.
6. **같은 원테이크 안에서 시간 점프·리프레임 금지** — 연속 대화는 통짜, x 고정. 끝점이 고정된 체인 컷은 `ss = 목표끝 - 컷길이`로 계산(나레이션 재생성 시 길이가 변한다).
7. **N블록 밑의 원본 소리에 대사가 섞이면 안 된다** — 뒤에서 그 대사가 풀 볼륨으로 또 나온다. 대사 시작 전에 컷을 끊거나 해당 컷만 mute.
7-1. **★나레이션 덕킹** — 원본 베드는 사이드체인 덕킹(`sidechaincompress`, 사이드체인=나레이션 wav): **발화 중 원본이 나레이션보다 ≥15 LU 낮게**, 발화 틈에는 자연 복귀(release 0.3~0.5s). 완전 무음 금지. 검증은 G13에 포함.
8. **맨살 확대 금지 / 무기·소품은 식별되게** — 얼굴 없는 몸통 클로즈업 금지, 총·칼은 보이되 과확대 금지.
8-1. **원본 화면에 박힌 자막이 컷에 딸려오면 안 된다** — 위치·부대 표기 등. 0.1초 간격으로 자막 영역 밝은 픽셀을 세어 **소멸 시각을 실측**하고 컷 시작을 그 뒤로. 컷 **시작 프레임**을 따로 확인한다.
9. **인물은 크롭 프레임으로 실물 확인** — 어깨·의상만 보고 짐작하면 다른 인물이다. 얼굴 보이는 프레임으로 확정.
10. **시간 전환은 완결형 문장으로** — "몇 분 전 상황입니다" / "다시 현재입니다". 두세 글자 스탬프 금지. + 되감기 whoosh 효과음.
11. **명장면(킥)은 절정 나레이션 아래 반드시 화면에** — 그 영화의 상징 장면 시각을 실측해 절정 카드에 배치.
12. **나레이션 정렬 텍스트에 숫자·단위 주의** — STT가 "팔 미터"를 `8`로 받아써 카드 정렬이 밀린다. 자막 표기는 아라비아, TTS/정렬은 한글 — (정렬용, 표시용) 튜플로 분리(코어 표기 규칙).
13. **자막**: 쉼표·마침표 금지(의문문 물음표는 표기) / 문장 경계 = 카드 경계 / 카드 5어절·13자 내외(최대 15자) / 대사 자막 한 줄 공백 포함 17자 한계 / 화자별 색 배정 / 원작 맥락에 기대는 조크는 대상을 보충 번역.
14. **폰트·스타일은 렌더 대조로만 판단** — 폰트 파일 내부 이름은 못 믿는다. 렌더 이미지 픽셀 diff로 기준본과 대조.
15. **효과음은 2~3곳만** — 오프닝 임팩트 / 시간전환 whoosh / 절정 스웰. `make_sfx.py`로 합성, 절제된 볼륨.
16. **출력 fps = 소스 영화 fps. 30fps 강제 금지** — 영화 소재는 대부분 24fps다. 올리면 매초 6장이 중복 프레임이 되어 뚝뚝 끊긴다. 소재 fps를 `ffprobe`로 실측하고 build·merge·finish의 모든 fps 하드코딩을 그 값으로. 렌더 후 `flow_scan.py`가 초당 중복 중앙값 ≥3이면 잡는다.
16-1. **★ffprobe가 30fps라고 그 영화가 30fps인 건 아니다** — 24fps 콘텐츠를 프레임 복사로 30fps에 담은 판본이 있다(20% 중복). `fps=24`는 위상이 중간에 바뀌어 실패하고 `mpdecimate`는 시간축을 파괴한다. 해법: **컷별 위상 실측 + 규칙적 5중 1 제거** — `fps_phase.py`의 `best_phase()`로 φ를 재서 컷 필터에 `select='not(eq(mod(n\,5)\,φ))',setpts=N/24/TB`(crop 뒤, scale 앞).
16-2. **★번개·조명 점멸 구간은 scene 검출을 믿지 마라** — 밝기 급변으로 가짜 경계가 수십 개 나온다. 폭풍우·플래시 구간은 0.3초 간격 프레임 시트로 실제 컷을 눈으로 찾아 수동으로 덮어쓴다.
17. **컷의 주 피사체 = 그 순간 나레이션·자막이 말하는 대상** — G4 "일치" 판정은 두 가지 다: ⓐ말하는 대상이 화면에 있다 ⓑ그 대상이 프레임의 주 피사체(중앙)다.

## 확정 스펙

### 규격
- **길이: 내용이 우선이다. 시간 제한은 "3분(180초) 이내" 하나뿐 (최우선 규칙)** — 기승전결이 완결되는 최소 길이가 정답이다.
  길이를 줄이려고 중요 장면·인과 고리를 자르는 것 절대 금지. 180초를 넘칠 때만 압축하되, 장면을 자르지 말고 나레이션 문장을 압축한다.
  실측: 추격전만 잘라 62.8초로 냈다가 "건너뛰고 결말 없음" 반려 → 기승전결 전체를 담은 101.6초가 승인. **처음부터 이야기 완결 기준으로 짜면 재작성이 없다.**
- 컷 중앙 1.6초, 0.8~4.8초 허용, 6.1초 초과 금지. 컷 밀도 분당 40~45컷 목표 (코어 컷 문법).
- 나레이션 말투: 문장을 맺는다 — ~ㅂ니다(최다)·~는데요·~었죠·~죠·~었습니다. 의문·명령·청유 금지.
- 구성·훅·펀치라인·설계표: **코어 1절이 원본** (품질 3기준 → 명장면 선입력 → 시작 패턴 후보 비교 → 드라마 설계표 6칸 → G17).
- D블록 자막은 직역 금지 — **의역해서 실감나는 한국어 대사로**. 욕설은 순화하되 감정 강도는 살린다.
  보기: `Move this fucking rock!` → "이 바위 좀 움직여"(반려, 어색) → **"제발 움직여 이 망할 바위"**(승인).
- **★원본에 박힌 한글 자막을 번역 기준으로 쓰지 마라** — 남의 번역이고 요약·오역이 섞여 있다. **원본 음성을 전사해 원어 문장을 확정하고 그걸 의역한다.**
- **★의역 전에 원어 문장을 전사 지도에서 그대로 인용해 확정한다** — 기억·어감으로 번역하면 뜻이 어긋난다. 콜백 조크는 뜻이 통하게 보충 의역.

### TTS (나레이션)
- Typecast `https://api.typecast.ai/v1/text-to-speech`, 키는 config의 `keys.typecast` 경로.
- **음성: 볼케이노 명화관 프리셋의 기본 배정 음성을 그대로 쓴다.** 특정 음성으로 고정하고 싶으면 config `tts_voice`에 voice_id를 넣는다 — 한 채널 안에서는 반드시 한 음성으로 통일.
- 후처리: `loudnorm I=-23 TP=-3 LRA=9` → `silenceremove(start -38dB/0.02, stop -38dB/0.20)` → loudnorm 재적용, 48k (templates/tts.py).
- 블록 프레임 수 = `ceil((wav초+0.10)*fps)`.
- TTS는 같은 문장도 재생성마다 길이가 흔들린다(2.17~3.07초 실측) — 빠듯한 샷에 걸 카드는 TTS를 뽑은 뒤 컷을 정한다.

### 자막 타이밍 (Speechmatics)
- 키는 config의 `keys.speechmatics`, batch v2, `language ko, operating_point enhanced` → 어절별 start/end → `sm_align.py`.
- 카드 경계 = 어절 시작 시각. 텍스트 매칭은 글자수 소비 방식(STT 오인식에 강함).
- 대사 카드 시각 = 블록 오프셋 + 조각 누적(오디오 조각 길이 그대로).

### 화면 스타일 (볼케이노 명화관 프리셋 기본을 그대로)
- **상하단 프레임 이미지(커튼·좌석)**: 볼케이노 `assets` 단계에서 받은 기본 이미지를 그대로 쓴다 — 이 플러그인은 이미지를 제공하지 않는다.
- **자막 스타일·폰트**: 볼케이노 명화관 프리셋 기본 스타일을 그대로 쓴다. 로컬 ass를 만들 땐 서버 산출 자막의 스타일 정의를 복제한다(PlayRes 1080×1920 기준). 헤드라인 2줄: 1행 흰색 / 2행 노랑, 렌더 폭 ≤1000px.
- 레이아웃: 1080×1920, 영화 화면 800×800 중앙 배치(y=420), 상단 헤드라인, 하단 자막 밴드.

### 상단 문구 (= 유튜브 업로드 제목)
- 영화 제목·배우 직접 노출 금지, 평균 20자, 2줄. **h1(윗줄) = 앞 10자 훅 자리** — 줄 나누기는 문법이 아니라 긴장이 걸리는 쪽을 h1에. **한 줄 실질 상한 12자**(13자부터 조합에 따라 1000px 초과).
- **패턴은 빈도순이 아니라 스토리 기준 선택 절차**: ①결말 직전이 제일 궁금하면 **결과 숨김**(`~한 일`·`벌어진 일`·`~의 정체`) ②"왜"가 반전이면 **이유형**(+「진짜」) ③오래된 작품은 **시간강조+숫자**(`N년 전`) ④감동·교훈 핵심이면 **잠언·의미정의** ⑤그 외 방법형·행동요약형. 실화 도장은 인물이 가공이면 「실화 기반」까지만. 금지 4종: 시청자 저격·금지형·ㅋㅋ말투·최상급 남발. **3안은 서로 다른 패턴에서 뽑는다.**
- 자동 완성 모드(기본): 추천 1안을 바로 적용해 완성하고, 납품 메시지에 3안 전문(패턴·자수·렌더폭 포함)을 **텍스트로** 첨부한다 — 채널 주인이 다른 안을 고르면 헤드라인만 교체해 합성 1회 재실행.
- 2행 렌더 폭 ≤ 1000px 검증 후 적용.

### 오디오 마스터
0. **★블록 빌드 필터에서 `loudnorm`을 쓰는 모든 자리 뒤에 `aresample=48000,asetpts=N/SR/TB` 필수** — 안 붙이면 G14 표류 버그.
1. merged 오디오 → `acrossover 120/720/4800 4밴드 + acompressor` 체인(mbc.wav — 파라미터는 템플릿 고정값)
2. `loudnorm I=-13.41 TP=-1.9 LRA=11` 2패스(측정→measured 적용, linear=true) + `alimiter limit=0.803526` + `apad whole_len=총초*48000`
3. 검증: **I -13.4~-13.7 LUFS, Peak ≤ -1.2dB**

### 전환(디졸브)
- 기본은 하드컷. 장면 대전환 2~4곳만 `xfade=fade`, 길이 **0.15~0.2s**, 밝기·색조 비슷한 샷 사이에만. 최종 렌더에서 디졸브 구간 실시간 재생 육안 판정.
- **★xfade 프레임 밀림**: ① xfade는 출력 프레임 1개 추가 → `trim=end_frame=` 강제 고정(merge 최종단 포함) ② offset 반올림이 1프레임 민다 → `off=frames/fps - 1e-4`를 `{off:.6f}`로. 안 고치면 자막이 화면보다 먼저 바뀐다.
- 블록 경계: 앞 블록 비디오에 테일 프레임(+9f) → merge가 `offset=앞블록 실길이`로 겹침(오디오·자막 타이밍 보존). 양쪽 `settb=AVTB` 필수.

### 효과음 (`make_sfx.py`)
- ① 오프닝 임팩트(0.03s, 피크 -10dB) ② 시간전환 whoosh(전환 0.3s 전, -16dB) ③ 절정 스웰(킥 나레이션 0.45s 전, -16dB)
- **믹스 `alimiter=limit`은 소재마다 다시 맞춘다** — 효과음이 피크를 밀어올려 G6를 넘길 수 있다. 목표 실측 피크 -1.3dBFS, AAC 인코딩 오버슈트 +0.2dB 감안.

### 2. 대본 확정
- 코어 1절 절차: 명장면 선입력 → 시작 패턴 후보 비교 → **드라마 설계표 6칸 + 도입 점검** (TTS 전) → **G17 냉관객 검사** (TTS와 병렬).
- 서버 초안 나레이션을 규칙에 맞게 손질: 문장 맺기, 시간전환 완결문, 화면에 없는 사물 언급 제거, 인과가 나레이션만으로 읽히게, 구어체(직역투 금지).
- TTS 생성 → Speechmatics 정렬 → 카드 타이밍 확보.
- **★정렬 직후 카드↔어절 대응을 전수 출력해 눈으로 본다.** 한 어절 밀린 채 컷 설계에 들어가면 TTS부터 되돌아간다. 어긋나면 카드가 아니라 **TTS 문구를 고쳐 재생성**한다.

#### 도입 점검 (TTS 전 — 안 하면 장면이 건너뛴다)
나레이션 카드 + 대사 자막을 순서대로 이어 하나의 글로 읽고: 처음 등장하는 **사람·집단·조직·장소·이동수단·무기** 전부에 대해 "그 앞에 무엇인지/어디서 왔는지가 있나"를 표로 점검. "없다"가 나오면 나레이션 문장과 그 주체가 나오는 컷을 함께 추가. 블록 경계에서 시간·장소·주체가 바뀌면 뒤 블록 첫 카드를 다리 문장으로. 마지막 자문: 블록 전환마다 "이게 왜 여기서 나오지?"가 생기면 고리가 빠진 것.

### 3. 컷 설계
- N블록: 카드 경계에 컷 경계 정렬. 컷마다 장면 후보를 시트로 고르고 기계 측정으로 x 확정 (사물 컷도 눈대중 금지).
- D블록: 오디오 조각 시각 = 비디오 시각(싱크). 원본이 그 대사 구간에서 샷을 바꾸면 우리 컷도 같은 지점에서 분할. 격자 스냅·DVID는 코어 3절.
- **★D블록 앞샷 꼬리 조각**: 컷 시작 직후 0.2초 안에 원본 샷 전환이 있으면 앞샷 꼬리 4~5프레임이 깜빡 튐으로 보인다. ①리액션 샷이면 비디오 시작만 원본 컷 뒤로 밀고 오디오는 그대로 ②원본 내부 컷 시각에서 우리 컷도 분할.
- 체크: 컷 0.8s 이상 / 장면경계 안 / 끝 -0.15s / 인물 실물 확인 / 반복 컷 없음 / 화자=화면 / 주 피사체=자막이 말하는 대상 / 말끝에서 딱 끊기.
- **★설계 lint (G10, 렌더 전 필수)**: 빌드에 컷 절대시각 dump(`work/cut_design.json`) → `cut_lint.py`. 컷 테이블을 고칠 때마다 재실행.

### 4. 렌더 → 조립 → 마스터 → 최종
**fps 먼저**: 소재 fps 실측 후 템플릿의 fps 하드코딩 전부 교체. build는 `work/cut_frames.json`(전역 프레임 번호)도 dump — G11이 이 표와 대조.
```
build.py     (블록 렌더 + captions.ass 생성)
merge.py     (블록 조립 + 경계 디졸브 → merged.mkv)
mbc → loudnorm 2패스 → master.wav
make_sfx.py + amix → master_sfx.wav
최종 render  (프레임 이미지 오버레이 + ass + master_sfx, [0:v]setpts=PTS-STARTPTS 필수)
```
각 단계는 **파이프로 잇지 말고 exit 코드를 단계마다 확인**(코어 3절 함정). 수정 후 merge 재실행 잊지 말 것.
핸드헬드 소재(화면이 계속 흔들리는 영화)는 build 뒤에 안정화 단계를 끼운다 — **롤을 컷 중앙값으로 고정**이 핵심(스무딩만으로는 개선 0), 크롭 800→740, 이동 보정 평균 0 정규화, 안정화 후 G3 재검증 필수.

### 5. 검증 게이트 — 전부 통과 전 납품 금지 (하나라도 실패 → 수정 → 전체 재검증)
게이트 표·기준·G17 절차는 **코어 4절이 원본** (G0~G17, G9 없음). 이 프리셋의 추가 세부:
- G3 플래그 기각은 렌더 프레임을 뽑아 주 피사체가 실제 중앙임을 확인했을 때만 — 기각 전에 그 시각이 어느 컷인지 cut_design.json으로 정확히 짚는다.
- G4는 전 카드 중앙시각 프레임 시트를 **눈으로 전수 대조**. 대사 카드는 추가 2열: ⓐ화자 얼굴이 프레임에 있는가 ⓑ자막 화자색 = 실제 화자인가.
- G12: 지도·초안 시각을 재전사 없이 믿고 오디오를 자르면 자막만 나오고 음악이 울린다 — 전 D블록 구간 재전사로 확인.

### 번인(하드) 자막 소재 대응
- 하단 자막은 800×800 상단 크롭이 잘라내지만, **아카이브 인서트·에필로그 구간은 자막이 화면 상단으로 이동**해 크롭에 걸린다. 컷 선정 전 그 컷의 크롭 프레임을 실제로 뽑아 전수 확인.
- **오디오만 추출한 파일은 원본과 시각이 어긋날 수 있다**(디코드 드랍 실측 4.05s). ASR 후 원본과 교차상관으로 여러 지점 대조, 점프가 있으면 구간별 오프셋 보정. D블록 오디오는 항상 **원본 파일에서 직접** 잘라 립싱크 보존.
- 아카이브 인서트는 가로 레터박스뿐 아니라 **세로 활성화면도 본편과 다르다** — 컷마다 상·하단 검은 행을 실측하고 컷별 crop y 지정.
